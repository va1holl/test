# 🧩 Static Site Generator (Python)

Невеликий генератор статичного сайту (**HTML + CSS**) на Python.  
Кожен запуск створює папку `dist/` з готовим сайтом, у якого автоматично змінюються:

- 🎨 кольорова палітра (8 варіантів),
- ✍️ шрифт (6 варіантів),
- 🔀 порядок секцій (Hero, Features, Contacts, Quotes, Pricing, Gallery, FAQ),
- 🧠 логічна випадковість усередині секцій (елементи <p>, <a>, <input> тощо міняються місцями),
- 💅 варіативність стилів (тіні, радіуси, відступи, адаптивна сітка).

---

## 🚀 Вимоги
- Python **3.8+**
- Жодних зовнішніх бібліотек — використовується лише стандартна бібліотека.
