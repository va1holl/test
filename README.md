# Генератор статичного сайту (Python)

Невеликий генератор статичного сайту (HTML + CSS) на Python.  
Кожен запуск створює папку `dist/` з готовим сайтом, у якого змінюються:
- rольорова палітра (2 варіанти),
- шрифти (sans / serif),
- порядок секцій (Hero, Features, Contact).

## 🚀 Вимоги
- Python **3.7+**
- Жодних зовнішніх бібліотек, лише стандартна бібліотека.
